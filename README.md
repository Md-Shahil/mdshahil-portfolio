## ✨ Features

* **Brutalist Aesthetic:** High-density layout with a focus on typography and neon accents.
* **Terminal Boot Preloader:** Fake terminal sequence on page load for a developer-themed UX.
* **Animated Tech Matrix:** Interactive grid showcasing technical skills with count-up animations.
* **Dark/Light Mode:** Smooth theme toggle with local storage persistence.
* **Fully Functional Contact Form:** Integrated with FormSubmit to deliver messages directly to my email.
* **Zero Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript—no frameworks required.

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3** (Custom Properties, CSS Grid, Flexbox, Keyframe Animations)
* **Vanilla JavaScript** (`IntersectionObserver`, DOM Manipulation, Fetch API)
